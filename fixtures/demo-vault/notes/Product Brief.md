# Product Brief

Flynt is a local-first project command center for markdown, tasks, diagrams, saved views, and embedded Omegon agents. This demo vault is intentionally small but connected enough to make the UI surfaces look populated.

## Goals

- Keep project knowledge in plain files.
- Make work legible through Write, Graph, Tasks, Design, and Omegon surfaces.
- Show agent context without exposing private operator state.
