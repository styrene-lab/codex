# Screenshot Capture Guide

Use a consistent 1440×900 window when capturing Flynt documentation screenshots from this vault.

## Staging

- Open [[notes/Product Brief|Product Brief]] for the Write surface.
- Keep the context panel visible when demonstrating resolved links.
- Hide private runtime paths unless the screenshot is specifically about `.flynt/` or `.omegon/` ownership.
